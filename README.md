# Kahan Lagayein? (پیسہ کہاں لگائیں؟)

A free, plain-language tool for Pakistanis: type an amount and see where it can go (National Savings, T-bills, money market funds, PSX, gold, REITs), how much it can grow after tax, and what is safe or risky.

- Static site: HTML, CSS and vanilla JS. No build step.
- Rates and facts live in `data.js` and `facts.js`, each with a source and date.
- Research behind it: `reports/` and `RESEARCH.md`.

Education, not licensed investment advice.
